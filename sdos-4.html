Connect your database

SdOS needs a Supabase project before real accounts can be created.

1. Create a free project at supabase.com
2. Open Project Settings → API and copy your Project URL and anon public key
3. Paste them into the SUPABASE_URL / SUPABASE_ANON_KEY constants near the top of this file
4. Open the Supabase SQL Editor, paste the contents of sdos_schema.sql (provided alongside this file), and run it once
5. Reload this page
